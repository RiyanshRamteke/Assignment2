# Constructors and Member Functions in C++

## Aim
To implement various types of constructors and member functions in C++.

## Problem Statement
To demonstrate the use of default, parameterized, and copy constructors along with a member function using a Car class.

## Constructors Used

### 1. Default Constructor
Initializes the car with predefined values.

### 2. Parameterized Constructor
Initializes the car using values passed as arguments.

### 3. Copy Constructor
Creates a new object by copying the data of an existing object.

## Member Function
`display()` is used to display the car's brand, model year, and price.

## Technologies Used
- C++
- iostream
- Dev-C++ / Code::Blocks

## Program Details
The program creates three objects using different types of constructors and displays their details using the `display()` member function.

## Sample Output

Default Constructor:
Brand     : Toyota
Model Year: 2022
Price     : 1500000

Parameterized Constructor:
Brand     : Honda
Model Year: 2024
Price     : 1800000

Copy Constructor:
Brand     : Honda
Model Year: 2024
Price     : 1800000

## Conclusion
The program successfully demonstrates the implementation of default, parameterized, and copy constructors along with a member function in C++.
